# A 股舆情策略前瞻观察协议（v0.4.3）

## 1. 当前冻结口径

`0.4.3` 是 2026-07-21 全量语义整改后的当前冻结版本。它覆盖以下完整链路：

- 新闻按板块/个股局部子句判定正面、负面和中性，负面扣分，中性不制造热度。
- 股票简称必须有代码、明确公司主语、公司业务语境或证券市场动作支持，普通中文子串不算个股命中。
- 前置主题子句必须具备板块/概念/产业链等引导词和明确方向；禁止同篇文章无关片段笛卡尔串联。
- 实体规则同时用于新抓取入口和聚合出口，最长 365 天的历史匹配缓存不能绕过新语义。
- normalized payload 单独保存局部方向；读取旧快照时按 `signed_score` 恢复，不再被整篇新闻方向覆盖。
- 个股直接新闻至少有一条正面、净分为正且时效分不低于 70 的可行动催化；约 6 天前的普通涨停新闻不能冒充今日买点。
- 主题资金只使用精确代表锚点；主题候选过滤在 SQL `LIMIT` 前完成；深 V/大振幅只给观察级；基本面读取公告日 PIT 版本。

## 3. 生产审计证据

2026-07-21 15:30 快照共 120 个板块/主题。较 15:15 快照，直接新闻股票边从 1,597 降至 1,449，其中主题直连从 383 降至 343；被剔除的是不能通过实体/关系复核的边，不以静态行业差异粗暴删除真实跨行业题材。

最新 normalized 快照逐边复算 2,564 条个股新闻边：关系规则失败 0；实体规则表面失败 1 条，经核对为 `华虹公司` 更名为 `华虹宏力` 的历史名称，不是误链。已知伪样本“驱动力←主要驱动力”“国新能源←我国新能源汽车”均只剩静态行业候选，不再拥有直接新闻；三花智控、东山精密、三环集团也不再被油价/黄金子句串到油气或有色主题。

`sh.603127` 当前只关联医疗保健/医药。其最近一条局部负面新闻时效约 69.8，两条局部正面新闻时效约 56，未达到 70 分可行动门槛，因此在硬过滤阶段退出当前结果，不再被旧涨停新闻选出。

历史 `a_share_sentiment` 结果共 136 条原样保留，其中原先纳入统计的 24 条已全部设置 `include_in_stats=0` 和 `evidence_validity=invalidated`。`0.4.0`～`0.4.2` 均未产生正式前瞻观察；正式样本只从 `0.4.3` 开始。

## 4. 冻结与变更规则

正式提交脚本逐次校验干净工作树、不可变标签、策略版本、配置哈希和全部信号路径源码。任何关系、方向、时效、阈值、数据口径或候选排序变化都必须新建版本和协议，不能继续写入 `0.4.3` 样本。
