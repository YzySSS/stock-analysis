# lowvol_reversal V2 绩效 DeepSeek 分析（2026-05-10）

## 1. 为什么修成真实因子后收益反而更差 —— 实现修复成功 vs 策略逻辑失败

**实现修复是成功的**  
- 旧版因子是离散的“基本面/数据质量”桶值，候选池内出现大量同分，最终靠 `code` 排序打破平局。旧回测的收益严重依赖巧合的字典序，不具备可重复的逻辑。  
- 新版用严格的平均秩百分位（0~100），完全消除同分依赖，使因子真正来源于市场行情——这是正确的工程重构，解决了“伪因子污染”的问题。  
- 旧版回测总收益 -4.3%，但若去掉平局随机性，其实际期望收益很可能已是负值。新版只是把伪装撕掉，暴露出真实因子在市场中的表现。

**策略逻辑在 2026 年这段行情中失败**  
- 新版回测收益 -62.8%，最大回撤 -67.5%，胜率仅 36.7%。从月度表现看，1 月勉强正收益（+0.30%），2 月开始转负，3 月暴跌（-2.39%/笔），之后连续重挫。  
- 策略逻辑是“低波动 + 超跌反转 + 高换手活跃度”组合，但市场进入单边下跌（尤其是小盘股、题材股）时，这三个因子会集中选出“已经暴跌且振幅收窄、换手依然偏高”的股票——这些股票往往是资金出逃途中的“半山腰接飞刀”，次日继续大跌，形成雪崩效应。  
- 因此，**收益恶化并非修复的失败，而是原策略逻辑在当前市场环境下的彻底失效**。

## 2. 当前公式的潜在问题（逐一分析）

### 2.1 20 日反转因子：超跌抄底陷阱  
`return_20d = (close - close_20d) / close_20d`，越低分越高。  
- A 股中存在大量连续阴跌甚至加速下跌的个股，20 日跌幅第一的股票可能正处在崩盘中途，次日大概率继续跌停或大幅低开。  
- 没有区分“正常回调后的反转”与“基本面恶化、资金出逃的暴跌”，缺少趋势过滤（如均线方向、量价配合）。  
- 1 日持仓周期加剧了这个问题：今天买入，明日开盘即卖，遇到一字跌停则无法成交，而回测中可能直接取开盘价（未模拟流动性），形成虚假亏损与实际不可交易的叠加。

### 2.2 turnover 方向：高换手给高分，可能反效  
`turnover_rate` 按 `higher_is_better=True` 计算百分位。  
- 在超跌股中，高换手往往代表多空分歧极大，卖方力量仍未释放完毕，次日继续下杀的概率高。  
- 回测最差交易中出现大量换手率极高（最高 32%）的个股，如金陵体育、三木集团等，伴随巨额亏损。  
- 低波动反转策略通常要求流动性适中而非极端活跃——应反过来“低换手更好”。旧版伪因子很可能隐含了低换手特征，新版彻底反转了这一方向。

### 2.3 lowvol 因子用振幅近似，缺陷明显  
`amplitude_20 = (max_close_20 - min_close_20) / close`。  
- 极值受单日尖峰（如天地板、尾盘偷袭）影响严重，可能将剧烈波动的股票误判为低波动，或者反过来。  
- 没有排除涨停、跌停导致的虚假振幅。  
- 波动率更好的度量是日收益率标准差或 ATR，同时应剔除极端值。

### 2.4 流动性过滤过松  
`avg_amount_20 >= 1,000,000`（100 万日均成交额）。  
- 这对 A 股来说门槛极低，大量壳公司、次新小票都能通过，它们的流动性风险巨大，买卖价差高，甚至在极端行情下无法买入/卖出。  
- 从重复入选样本看，多数是 sz.001xxx（深市小盘新股）、sh.603xxx（小盘次新），平均回报为负且波动极大，正是流动性陷阱的受害者。  

### 2.5 无趋势/风险过滤  
- 完全没有市场状态判断（如中证全指 20 日均线方向），在单边下跌市依然满仓买入，导致 3 月之后回撤呈自由落体。  
- 缺少单票风控，如“当日跌幅超过 9% 不买”“次日跌停无法卖出则不参与”等。  
- 没有止损机制，完全依靠固定 1 日开盘退出，在极端行情下会出现连续暴跌且无法出逃的情况（回测中可能被低估）。

### 2.6 因子合成与排序细节  
- 三因子线性加权 `turnover*0.35 + lowvol*0.35 + reversal*0.30`。在百分位为 0~100 时，分数主要由各因子高位叠加决定，会集中选出“反转分极高、低波分极高、换手分极高”的极端股票，集中度风险极高。  
- 排序 tie-breaker 使用 `reversal`、`lowvol`、`turnover` 再 `avg_amount_20` 和 `code`，人为偏好多因子高分股票，反而放大了尾部风险。

### 2.7 1 日回测模式的滑点与可交易性缺失  
- 买入日开盘价买入、次日开盘价卖出：隐含假设开盘价可以无障碍成交，但实际上跌停板开盘无成交或成交量极小，回测收益被美化。亏损最大的交易中有“金陵体育次日 -14.86%”，这可能是一次跌停到开盘价直接兑现的极端情况，实盘可能根本卖不掉，亏损更大。

## 3. lowvol_reversal_v2.1 合理方案（针对 A 股）

### 3.1 因子重构  
**主因子：短期反转（5 日） + 低换手 + 低波动（收益波动率）**

- **反转因子**：`ret_5d = (close - close_5d)/close_5d`，越低越好。  
  加入趋势保护：只有 `close > ma_60`（或股价位于 60 日均线上方）时才给反转高分，否则惩罚。
- **低换手因子**：`turnover_rate_5d_avg`（近 5 日均换手率），**越低越好**（反向百分位）。  
  目的是选择抛压衰减、筹码沉淀的股票。
- **低波动因子**：`std_20d`（近 20 个交易日日收益率的年化标准差），越低越好。  
  使用收益率的标准差而非价格振幅，更稳健，排除涨停跌停日。

### 3.2 过滤条件（严格化）  
- `is_st == False`  
- `上市天数 >= 60`（剔除次新股）  
- `close > 2`  
- `日均成交额（20日） >= 5,000,000`（500 万，可上调至 1000 万）  
- `当日涨跌幅 > -9.5%`（剔除即将或已经封死跌停的股票）  
- `当日换手率 < 20%`（防止极端放量）  
- `close < upper_limit * 0.99`（非涨停板）  
- 有可用的 `open` 价格且 `open > 0`  

### 3.3 市场择时风控  
- 计算中证全指（000985）或沪深 300 的 20 日均线。  
- 仅当 `close_index > ma_20_index` 时允许开仓，否则空仓（或降低最大持仓数）。  
- 增加**熔断机制**：若策略最近 5 个交易日累计收益 < -8%，暂停交易 3 天，避免连续暴跌。

### 3.4 因子合成与选股  
- 每个因子计算日截面百分位（0~100），等权加总得到 `score = (rev_pct + low_turn_pct + low_vol_pct) / 3`  
- 按 `score` 降序排列，取前 `max_picks` 只（默认 5 只），不再设固定阈值。  
- 单票仓位等权，每日调仓，买入开盘价，卖出次日开盘价，但加上流动性检测：次日开盘量比 > 0.3（确保有成交），否则递延到下一可交易日。

### 3.5 回测参数建议  
- `max_picks = 5`  
- `return_mode = 1d` 保留，但加入“跌停不可卖”模拟：若次日开盘涨跌幅 <= -9.8% 且开盘量极少，则假设无法卖出，顺延至下一个满足条件日，且承担 2% 的额外滑点。  
- 计入双边佣金 + 印花税（万 2.5 + 千 1）。

## 4. 最小可实施修改清单（优先级排序）

**P0（阻塞性）**  
1. 增加“当日跌停/极端跌幅”过滤：`当日涨跌幅 > -9.5%`。  
2. 提高日均成交额门槛至 `>= 5,000,000`。  
3. 修改 turnover 方向为 **低换手**（`higher_is_better=False`）并改用 5 日均换手率。

**P1（关键效果）**  
4. 将 reversal 从 20 日改为 5 日 (`ret_5d`)。  
5. 添加趋势保护：仅当 `close > ma_60` 时反转因子有效，否则置为 50（中位）。  
6. 替换 lowvol 因子为近 20 日日收益率标准差（`higher_is_better=False`）。

**P2（辅助增强）**  
7. 加入市场择时：中证全指 `close > ma_20_index` 才开仓，否则空仓。  
8. 增加上市天数 >= 60 过滤。  
9. 修改因子合成为等权平均，去除 tie-breaker 中的 `code`，改用随机或成交量。  

**P3（风险控制）**  
10. 实现回撤熔断（连续 5 日累计 < -8% 暂停 3 日）。  
11. 模拟跌停不可卖：次日开盘涨幅 < -9.8% 且量比低，顺延卖出。

## 5. 下一轮回测实验组设计（至少 5 组）

所有实验组均在同日期段（2026-01-01 ~ 2026-05-10）运行，保持其他条件不变，以便直接对比。

| 实验组 | 说明 | 关键差异 |
|--------|------|----------|
| **G1 (现状基线)** | 完全复用当前 v2 代码（不加任何修改） | 作为亏损对照组 |
| **G2 (仅反转 5d + 严过滤 + 无择时)** | 因子 = 5 日反转（越低越好），过滤条件加强（均额 500 万、跌停剔除、上市 60 天），无 turnover 和 lowvol | 验证纯反转威力 |
| **G3 (反转 5d + 低换手 + 严过滤 + 无择时)** | 反转 5d（越低越好）+ 换手率 5d 均（越低越好），等权合并，过滤同 G2 | 检验低换手是否改进 |
| **G4 (G3 + 低波动标准差)** | 反转 5d（带 60 日趋势保护）+ 低换手 5d + 低波动 20d 标准差，等权，严过滤 | 完整三因子，无市场择时 |
| **G5 (G4 + 市场择时)** | 在 G4 基础上，加入中证全指 20 日均线上方才开仓，否则空仓 | 观察市场择时能否躲过大跌 |
| **G6 (G5 + 跌停卖不出模拟 + 熔断)** | 完整风控版本，加入跌停顺延卖出、滑点、回撤熔断 | 评估风险调整后收益 |

如果计算资源允许，可再加一组 **G7 (反转 10d 替代 5d)** 来对比反转周期长短。

## 6. 是否建议保留该策略

**当前建议：立即转为“研究态/实验态”，严禁实盘。**  
理由：  
- 新版在 2026 年初的实盘环境（或样本外）中出现了 -62.8% 的毁灭性回撤，逻辑已证明无法直接用。  
- 即便改进后，也需在**至少两个独立时间段**（如 2023-2024 和 2024-2025）通过滚动样本外验证，并且**实盘模拟（paper trading）不少于 3 个月**，确认稳定正收益后才能考虑小规模上线。  
- 低波动反转策略高度依赖市场环境，一旦市场风格转为趋势下跌或“杀小票”，该策略会迅速爆亏，因此必须将其归类为**有条件使用的研究策略**，并注明仅在特定市场状态下运行。

---

**总结**：新版重构是干净的，但暴露了因子本身的致命缺陷。下一步需按优先级实施 P0~P3 修改，并用多组对照实验找到可能有效的因子组合，同时绝对不能让“裸奔”的 v2 进入生产。
