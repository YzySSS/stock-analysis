## 2. 候选方向与禁止事项

预留候选策略 ID 为 `pit_quality_trend_liquidity_v1`。研究假设是：公告日 point-in-time 质量信号，加中期趋势确认，再加流动性/风险准入，可能比已经否决的低波反转和 V13 三因子更稀疏、更能覆盖交易成本。

允许进入评分或确认层的输入只有：

- `stock_fundamental_pit` 中信号日已公告的 ROE、ROA、毛利率、净利率、营收同比、利润同比、EPS；
- 信号日及以前的日线价格/成交量构造的中期趋势确认；
- 信号日 point-in-time 流动性、生命周期、名称/ST、停复牌等硬准入和风险约束。

明确禁止：

- 给 `lowvol_reversal` 或 `v13_three_factor` 换权重、换阈值后起新名字；
- 把低波或短期反转继续当正向 alpha 主因子；波动率最多作为硬风险约束；
- 使用绝对股价加分，或在无信号时强行补满 3 只；
- 在历史日期读取当前基本面、当前名称/ST、当前上市/停牌状态或当前指数成分；
- 看完结果后挑最好的持有期、offset、阈值或公式；
- 修改现有两份 V2 前瞻实验指纹覆盖的旧策略/回测文件。

新策略最多选 3 只、最少为 0，只要门槛不满足就持币。完整因子公式、标准化、入场阈值和分数区分度门槛只能在开发集上确定，并须在触碰历史诊断集前形成独立 `factor_spec_v1.yaml + SHA-256`。

开发阶段最多登记 12 份候选 spec，所有候选都必须留痕，不能只保存赢家。

## 4. 执行、成本和数据合同

执行口径在写代码前已经固定：

- T 日收盘后，且只使用 T 日收盘前可知信息形成信号；
- 下一可交易日开盘成交；
- 主持有/再平衡周期固定为 5 个交易日；
- 必须分别运行 offset `0/1/2/3/4`，五条非重叠周频路径全部报告，不能挑最好的一条；
- 最大 3 个持仓，可空仓；停牌或无法成交时按明确的执行约束处理并留痕；
- 佣金每边 3 bps、卖出印花税 5 bps、滑点每边 5 bps。

主股票池固定为历史 point-in-time 全 A，沪深 300 为基准，并作为预声明的稳健性股票池。未知生命周期、ST、停复牌、公告日基本面或指数成分一律 fail-closed。

当前回测基线使用未复权一日收益，新候选不能沿用这个限制进入实现锁。实现锁之前必须具备用原始开盘价模拟成交、同时按 point-in-time 公司行动正确计算总回报的能力；缺少调整数据时状态只能是 `blocked before implementation_lock`，不能静默改回未复权收益。

## 5. 验收门槛

真正前瞻窗口固定 252 个沪深 300 交易日，至少 240 个完整信号日。每个 offset 至少完成 90 个持仓样本，基准覆盖率至少 98%，PIT 数据质量必须 ready，配置和源码指纹必须完全匹配。

所有结果均扣除冻结成本。五个 offset 必须同时满足：

- 净总收益不低于 0；
- 对沪深 300 的净超额收益不低于 0；
- 各 offset 最大回撤不低于 `-20%`；
- 各 offset 正超额季度占比至少 50%；
- 各 offset 日超额 bootstrap 均值 95% CI 下界不低于 0；
- offset 夏普率中位数至少 0.5；
- 每次再平衡的平均替换比例不高于 50%；
- 沪深 300 成分股稳健性切片的 offset 中位净超额不得为负，但该切片不能挽救主股票池失败。

分数区分度是硬门槛，但数值必须和完整评分尺度一起在 `factor_spec_lock` 阶段冻结；历史诊断后不得放松。如果样本数、数据、调整收益或结构检查不足，结论是 `inconclusive`，不是降低门槛。
