- 依赖：`requirements.lock.txt` 固定本次通过测试的 Python 3.12 venv 包版本；没有在本轮升级依赖，也不声称已做跨平台锁或 wheel 哈希供应链验证。
- migration `0038`：仅用非唯一候选版本索引替换旧唯一索引，保留 campaign_id 唯一约束；真实 smoke 幂等通过，生产 23ms 应用，原 2 个 campaign 字节级数据比较一致；备份位于 `/root/stock-analysis-backups/research-cohort-20261112_192721/`。
