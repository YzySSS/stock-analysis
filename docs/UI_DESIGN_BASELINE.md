## 页面结构

| 页面 | 内容优先级 |
| --- | --- |
| 首页 | 标题与行动 → 风险提示 → 上证/深证/创业板真实指数卡与迷你折线 + 市场广度 → 左指数分时/日收盘折线与成交量、右主线周期 → 左最近跟踪表/右板块资金条 → 其他市场证据展开条 |
| 选股中心 | 运行配置 + 策略/数据状态 → 独立运行状态条 → 结果表及研究明细 |
| 跟踪复盘 | 左对齐的策略/选股日期/每页数量/刷新过滤条 → 左统计与紧凑复盘表/右观察检查器与备注归因 → 完整数据与操作显式切换 |
| 持仓管理 | 标题与单排汇总 → 持仓表 + 诊断 → 行业分布 + 手动录入表单 |
| 回测中心 | 研究口径 → 左侧参数 / 右侧净值与结果 → 日级与交易明细 |
| 选股策略 | 左显式策略版本与版本记录时间线 / 右名称和版本徽标；因子权重与参数并排、数据就绪摘要横跨；下接建议质量/执行纪律双栏，协议/完整参数/完整就绪证据/历史诊断展开 |
| 交易策略 | 横向策略选择 → 左编号规则/右参数概览 → 独立三步使用流程及前往回测 |
| ETF 轮动 | 真实空候选/数据阻断条 → 四项统计单轨 → 候选表 + 固定口径/覆盖 → 前向观察 |
| 数据状态 | 真实健康摘要 → 数据基准 + Worker/队列 → 任务监控 → 数据质量与结构化错误 |
| 个股详情 | 横向真实报价 → 日K/周期控制 + 策略摘要 → 估值/基本面/资金三卡 → 新闻/复盘/筹码三卡 → 可展开分时 |
| 登录 | 55/45 品牌与表单分栏，简洁无导航 |

## 功能与证据约束

- 保留现有 API、表单字段、DOM ID、认证/CSRF、任务取消/刷新/分页与研究语义。
- 真实登录需要**用户名+密码**，这是相对于概念图“仅密码”的明确兼容性例外，不改认证合同。
- 首页指数使用独立只读腾讯报价/分时/日线链路，不能复制概念图示例数值或用行业截面冒充指数曲线。分时和近60个交易日日收盘均用折线，成交量来自同一真实序列。
- 明确保留供应商上海时区的交易日与报价时间，非交易时段不能把上一交易日行情称作今日实盘。报价与迷你分时日期不同则不混画；供应商失败时显示缺数据，15分钟内旧缓存必须标识，不能合成路径。
- 指数显示链路不作为策略输入，不写市场研究快照或改变选股/择时判断。市场强度、涨跌停与行情时钟仍可展开，不因概念图的三指数卡布局而丢失现有内容。
- 概念图中的搜索涵盖策略；本版明确标为“搜索股票代码”，沿用真实个股跳转，不虚构全站检索能力。
- 股票搜索接受六位代码、`sz.000725`/`SH600000` 与 `000725.SZ` 等表示，跳转前统一为生产真实代码格式；不把用户输入原样送入一个必然 404 的六位代码详情页。
- 研究策略仍显示仅研究/尚未验证；合法空候选、缺数据、失败与历史污染状态不美化成成功。
- 首页市场普跌提示仍为强提醒而非拦截，真实持仓仍为手动管理，不新增交易或自动晋级。
- 涨跌数字和 K 线使用红涨绿跌；非行情研究曲线使用蓝色，不能让颜色暗示策略有效。

## 实现入口与维护

统一样式位于 `app/api/web/css/dark-design.css`，真实 11 页通过 `data-ui="dark-v1"` 显式启用并最后加载。
旧页面 CSS 只承担既有组件结构；后续新增 UI 必须使用此设计语言，不再堆叠其他主题。
`app/api/web/js/common.js` 负责导航辅助与搜索交互，不改变任何业务判断。
修改基准需用户明确批准新的设计方向；正常修复溢出、可访问性、移动端与数据兼容不视为变更设计。

## 用户二次指出的三个缺项（2026-11-13）

1. **首页指数和折线不是可永久豁免的功能差异。** 已补 `/api/dashboard/indices` 与 `/api/dashboard/index-series`，上证/深证/创业板三卡和迷你折线、主区分时/日收盘折线、成交量、周期和指数切换均可用。原行业柱状截面退出主图区。
2. **版本信息不得被样式隐藏。** 策略卡与详情都明确显示注册表版本，左侧版本记录来自真实注册描述/不可变标签；0.5.0 污染历史从真实 `supersedes` 元数据展开追溯，不发明发布日期，也不把它重新注册为可选策略。初始详情只查看最新注册版本，不改变选股默认策略或自动晋级。
3. **跟踪过滤条显式左对齐。** 覆盖旧 `justify-content:flex-end`；策略、选股日期、每页数量标签对齐，输入框底边齐平，刷新按钮紧随；手机改为左对齐的全宽纵排。

本轮只复拍三个改动页：每端3页×桌面/手机共6视图，本地和公网合计12视图，
每端12项针对性交互/原DOM ID保留与唯一性断言通过，无未捕获JS异常或整页横向溢出。
独立 Python 回归683项执行（682通过、1个既有skip）；6个页面/资源磁盘、本地、公网哈希一致。
原图/上一版/本轮对比与只读验证脚本留在本机 `output/ui-three-corrections-20261113/`，
不把旧11页截图冒充本轮新验收，不公开提交真实账户截图。
