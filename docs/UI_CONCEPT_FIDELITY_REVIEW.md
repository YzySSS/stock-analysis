## 不可直接照搬的内容

- 参考图并不完全自洽：导航图标和 logo 在不同 PNG 中有生成差异。本轮以首页的几何柱形标和
  同类细线图标系统统一，不在不同实页任意切换品牌或笔画。
- 当前 Dashboard API 不提供概念图中的上证/深证/创业板指数分时序列。
  主图位置显示**真实行业涨跌截面**，明确标识“非指数分时”；不把示例指数或虚构蓝线填入生产。
- 真实登录需要用户名和密码。保留两个字段、登录校验、过期与授权限制，不能照图删除用户名。
- 真实交易规则有五种，保留全部选择；桌面横向选择带可滚动，而不是为凑三张卡删除两种规则。
- 真实因子/候选/股票/任务多于概念图。第一层保持图稿的模块与列优先级，完整字段通过滚动、
  折叠或显式切换访问；不删除、补造或改变研究事实。
- 观察检查器只连接入选价和最新价两个实测点，明确写明仅两个时点，不伪造 1/3/5 日路径。
- 参考图中的示例成功/完整/有候选与当前真实状态不同。真实缺证、合法空结果、失效和历史污染状态照实显示。

## 可复验的视觉与交互方法

1. 先固定同一视口 1672×941，对照原 PNG 的外壳边界与主网格；手机另测 390×844。
2. 单个 Chromium、单页面串行访问公网 11 页，等待真实 API 装载，拦截全部业务写请求。
3. 截图逐页复核图标、logo、主要模块顺序、分栏及密度，修复旧 CSS 的高优先级反盖。
4. 保留概念图/首轮实页/本轮实页三列对比，证据留在本机 `output/ui-concept-fidelity-20261113/`，
   不把真实账户/行情截图提交 Git。
5. 检查每个新展开/明细开关、观察检查器、原选股/回测/登录/导航交互；检查所有原 DOM ID 保留。
6. 检查本地与公网页面/资源哈希、认证隔离、health/readiness；纯静态改动不重启 API 或 Worker。

“通过无溢出/无异常”不是“像素级相同”。本轮的结论应是结构与图标还原修正，
仍需明确上面的真实数据与功能差异，不能声称 100% 像素一致。
