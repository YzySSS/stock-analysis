# A 股舆情策略前瞻观察协议（v0.4.0）

## 1. 为什么重启观察

`a_share_sentiment 0.4.0` 是一次语义修正版，不延续 `0.3.x` 的统计证据。全量审计确认旧链路存在文章内“股票 × 板块”笛卡尔关联、负面新闻正向加分、主题资金模糊串联、主题候选先截断后过滤、深 V 反抽误标可交易，以及当前选股读取非 point-in-time 基本面等问题。

旧结果不会删除；它们会保留原始内容，并以 `evidence_validity=invalidated` 标记，从有效跟踪统计中移出。这样既能追溯历史，也不会把不同语义版本混成一条胜率曲线。

新协议 ID：

```text
a_share_sentiment_v0_4_0_after_close_v1
```

## 2. 0.4.0 冻结语义

- 股票与静态行业可以直接关联；跨行业主题必须在同一子句、紧邻前置主题子句或明确因果子句中成立，禁止整篇文章内任意组合。
- 新闻方向分为正面、负面和中性；负面贡献为负，中性不贡献正向个股分。
- 个股直接新闻候选必须至少有一条正面、可行动新闻，且正负净分为正。
- 主题资金流只允许命中冻结的精确代表锚点；没有可靠代表指数的宽泛主题按中性资金处理。
- `allowed_sector_types` 和排除项必须在数据库 `LIMIT` 前执行，避免错误类型占满候选窗口。
- 盘中低点不高于昨收 `-8%` 或日内振幅不低于 `10%` 时，即使收盘前强力修复，也只标记为观察级。
- 当前舆情选股的 ROE、ROA、利润增长和 EPS 只读取信号时点已经公告的 `stock_fundamental_pit` 版本；盘中不读取当天收盘后才可见的公告。

## 3. 固定前瞻合同

| 项目 | 固定值 |
| --- | --- |
| 策略 | `a_share_sentiment` |
| 策略版本 | `0.4.0` |
| 每日执行 | 交易日收盘后 `16:20 Asia/Shanghai` |
| 分数底线 | 60 |
| 最大候选 | 3；允许 0 只 |
| 入场口径 | 信号日后的首个可交易日开盘价 |
| 观察周期 | 1 / 3 / 5 / 20 个交易日收盘 |
| 基准 | 沪深300、中证500、中证1000 |
| AI 口径 | 记录真实 progressive AI / partial AI / local fallback，分段报告 |
| 初步可读门槛 | 20 个成功观察日或累计 50 个候选 |
| 不可变标签 | `a-share-sentiment-v0.4.0` |

达到初步可读门槛只会进入 `preliminary_ready`。`validation_status` 继续保持 `unvalidated`，不能据此宣称策略有效、自动下单或升级为默认策略。

## 4. 冻结与追溯

正式提交脚本会校验工作树、不可变标签、配置哈希和所有影响信号的源码，包括新闻聚合脚本、股票—板块语义、统一主题词典、候选 SQL、策略因子与交易计划。任一冻结路径漂移都会 fail-closed，必须建立新版本和新协议，不能把改过的逻辑继续写进 `0.4.0` 样本。

旧版协议文档 [`a_share_sentiment_forward_observation_2026-07-21.md`](./a_share_sentiment_forward_observation_2026-07-21.md) 仅作为 `0.3.1` 历史合同保留，不再代表当前运行口径。
