# 低波反转策略 v2.1 全区间结果 DeepSeek 分析（2026-05-11）

## lowvol_reversal v2.1 全区间回测分析（2026-05-10）

### 1. v2.1 相比 v2 的改善与持续亏损原因

**改善点（有效）**
- 风险过滤生效：`pct_chg_1d <= -9.5%`（剔除跌停）、`min_avg_amount ≥ 500万`（流动性门槛）、`max_turnover_rate < 20%`（极端换手过滤）、`min_listed_days ≥ 60`（次新剔除）显著压低了尾部极端亏损。v2 最差单笔 -14.86%，v2.1 最差 -3.37%（大豪科技 sh.603025），尾部风险被有效截断。
- 持仓集中在低换手、相对大盘的标的（伊利股份、双汇发展、华润三九、中远海控、江苏银行等），已摆脱 v2 的壳股次新特征，选股池质量明显提升。
- 总收益从 -62.8% 提升到 -21.3%，回撤从 -67.5% 压缩到 -21.96%，风险调整改善幅度超过 40 个百分点。

**仍亏损的根本原因**
- 因子方向本身仍未产生正 alpha，只是过滤掉了最致命的下行。
- 趋势保护（`close > ma60`）未能阻止下跌市中的买入：2026 年 1 月下旬起大盘转弱，大量标的在跌破 MA60 边缘被选中，随后继续破位。
- 5 日反转在震荡下跌市中表现为“刚刚破位就买入”，半山腰接刀的性质未变，只是刀没有 v2 的 20 日反转那么陡。

**核心矛盾**: 过滤做好了“不买最烂的”，但没有解决“该买什么能涨”。

### 2. Selected-only CI 分析：各因子有效性与方向

**重要前提声明**
当前 CI 是 **selected-only 局部秩相关**，不是全候选池横截面 IC。原因：
- `factor_json.raw_metrics` 未写入 v2.1 专属原始因子字段（`std_return_20`, `return_5d`, `trend_ok`, `turnover_rate_5d_avg`），无法回溯全候选池。
- 只能计算 240 笔被选中交易的因子分-收益关系，存在严重的幸存者偏差和预测偏差（选入本身就依赖因子排序极端值）。

**基于 sample_factors 和 worst20 的初步判断**

| 因子 | 方向 | 初步结论 | 证据 |
|------|------|----------|------|
| turnover（低换手） | 越低越好 | **方向大概率正确** | 被选标的换手率集中在 0.3%~0.9%，远低于全市场；极端放量已被过滤；但因子 IC 在当前区段是否为正无法验证（selected-only 的 turnover 分变异太小） |
| lowvol（20日收益标准差） | 越低越好 | **方向可能正确，但区分度不足** | 样本股 lowvol 分基本在 90+，说明选到的都是极低波动股；但这些低波股在 2-4 月照样跌（银行、消费白马补跌），说明低波只避了波动风险，没避趋势风险 |
| reversal（5日，趋势保护） | 越低越好 | **方向存疑，趋势保护可能失效** | 多数被选标的 reversal 分也在 80-90+（即 5 日跌幅大），说明买入时标的已跌了几天；`close > ma60` 只保证不买深度熊股，但刚从 MA60 上方破位下跌的标的仍然会被选中并在次日继续下跌。worst20 中大量 `ret < -2%` 的交易出现在银行、港口等“刚破位”的标的上 |
| score（综合） | 越高越好 | **无明显单调性** | 最差的几笔交易（-2%~-3%）score 都在 90-97 区间，月均 -0.4% 收益的情况下高分根本不能保证正收益；最高分标的反而集中出现在 3-4 月的重灾区 |

**初步结论**:
- lowvol 和 turnover 的方向大体合理，但它们选出来的都是“趴着不动”的股票，在市场整体下跌时一样会阴跌。
- reversal 是当前亏损的主要来源——5 日跌幅 + 趋势保护的组合在 2026 年的震荡下跌市中只是一个更精细的“接飞刀”信号，不是反转信号。

### 3. 净值曲线分析：为什么从 1 月底开始持续下台阶

**阶段分解**

| 时间段 | 市场特征 | 策略表现 | 累计收益 | 原因 |
|--------|----------|----------|----------|------|
| 1/5-1/23 | 窄幅震荡/偏强 | 勉强正收益 | +0.52% | 选到伊利、双汇、华润三九等消费白马，短期回调后有反弹 |
| 1/26-2/2 | 开始下跌 | 连续重挫 | -6.5% | 中信特钢、金达莱等标的 5 日跌幅触发买入，次日继续下杀；1/28-29 单日 -1.7%~-1.6%，两日抹掉前面全部盈利 |
| 2/3-2/13 | 弱反弹 | 略回血 | -6.47% | 低波反弹特征：涨的时候能跟一点，但力度弱 |
| 2/24-3/23 | 再度下跌 | 加速亏损 | -14.7% | 市场二次探底，银行股（江苏银行、杭州银行、宁波港）开始被选中——“低波 + 跌破均线”的银行成为标准补跌标的；3/23 单日 -2.53% |
| 3/24-4/2 | 短暂企稳 | 小幅反弹 | -14.43% | 反弹仍然不足弥补亏损 |
| 4/3-5/8 | 阴跌不止 | 持续下台阶 | -21.3% | 中国国贸、海天味业等白马补跌；4 月胜率仅 28.57%，是全部月份最低；市场无论牛熊，低波反转标的都在跌——说明选股逻辑本身与市场方向无关 |

**关键洞察**: v2.1 没有市场择时，在下跌趋势中选的“低波+超跌+站上均线”组合，刚好对应“高位回调的防御性股票”——这类股票在熊市中后期往往成为补跌主力。策略 2-4 月的亏损正是补跌逻辑的体现。

### 4. 数据与记录缺陷

**P0 - factor_json raw_metrics 未记录 v2.1 专属字段**
- `backtest_pick.factor_json.raw_metrics` 中确实没有 `std_return_20`, `return_5d`, `trend_ok`, `turnover_rate_5d_avg` 这四个 v2.1 计算并使用的原始因子值。
- 这是代码缺陷：`factor_json` 记录逻辑使用的是 v2 时期写入的通用字段（`close`, `turnover_rate` 等），v2.1 新增因子的原始值仅在 `raw_lowvol_reversal_metrics` 内存结构中出现，未被持久化到 `factor_json.raw_metrics`。
- **后果**: 无法计算全候选横截面 IC/Rank IC，所有因子诊断只能依赖 selected-only 局部数据，归因精度严重受限。

**P1 - selected-only CI 的固有局限**
- 选股策略天然截断因子分布，只有排序极端值进入交易样本。即使全截面某个因子有正 IC，在 selected-only 中也可能表现为零或负相关——因为你在尾部切片中观察，变异范围被压缩。
- 无法区分“因子失效”和“因子单调性在尾部缺失”。
- 必须用全候选池数据做横截面因子测试（含因子值分布、IC 序列、分层收益）才能做出可靠的因子归因。

**P1 - 无市场择时，导致 alpha 与 beta 高度混杂**
- 策略全程满仓（持仓 3 只），在下跌市中完全暴露于 beta。当前 -21.3% 收益中，纯 beta 贡献可能占 -15% 以上，因子 alpha 真实贡献未知。

### 5. 最小下一步开发计划

**优先级排序（数据质量优先，然后修复因子，最后重构）**

| 优先级 | 任务 | 理由 | 预计工作量 |
|--------|------|------|------------|
| **P0** | 修复 `factor_json` 记录逻辑：持久化 `raw_lowvol_reversal_metrics` 的全部字段到 `factor_json.raw_metrics` | 当前归因盲飞，不修无法进行任何严谨的因子分析 | 小（修改 backtest runner 1-2 处代码） |
| **P0** | 重新运行 v2.1 全区间回测（1 次），确认新记录的 raw data 完整 | 验证修复是否生效 | 等一次回测耗时的成本 |
| **P1** | 基于全候选池计算 **全截面 Rank IC**（turnover / lowvol / reversal / score），按日、按月聚合 | 这是因子是否有效的唯一可信证据。如果三因子 Rank IC 均为零或负，继续调参无用 | 中等（需离线分析脚本） |
| **P1** | 计算 beta 分离：用 000985 日收益回归策略日收益，提取 alpha 序列 | 区分市场下跌和因子失效的各自贡献 | 小 |
| **P2** | 如果全截面 IC 显示 reversal 方向错误，考虑反转方向（`higher_is_better=True`）或替换为动量因子 | 基于数据决策，不猜 | 取决于分析结果 |
| **P2** | 如果低波+低换手 IC 正向但不稳定，加入市场择时（如 `close_index > ma20_index`）后测试 | 低波因子可能只在非恐慌期有效 | 中等 |
| **P3** | 实验组设计: G1=v2.1 重现(确认记录修复), G2=全截面 IC 最优单因子, G3=双因子最优组合, G4=三因子+择时 | 系统性迭代，不要一次改太多 | 取决于前面分析 |

**禁止行为**: 在没有全截面 IC 证据的情况下盲目调参、换窗口、加因子。当前的问题是因子逻辑可能根本不产生 alpha，不是参数不优。

### 6. 策略风险定级与实盘建议

**当前定级: 研究态 / 暂停实盘**

理由:
1. 连续 4 个月稳定亏损，总收益 -21.3%，无任何一个月正收益，已排除“短期运气差”的可能性。
2. 因子有效性的基础证据（全截面 IC）全部缺失，无法证明策略存在正向 alpha。
3. 没有市场择时，在下跌市中是纯 beta 暴露，风险不可控。
4. `factor_json` 记录缺陷导致归因能力为零，继续运行只会产生不可解释的亏损。

**恢复实盘/实盘模拟的最低条件**:
- 全候选横截面 Rank IC（reversal / lowvol / turnover）至少一个因子为正且统计显著（|t|>2.0）。
- 样本外测试（建议 2024-01 至 2025-12，覆盖一轮牛熊）累计收益为正，最大回撤 < 15%。
- 加入市场择时或 beta 对冲后，alpha 部分为正。

在满足以上条件前，策略应标记为 **“研究态-未验证”**，禁止在任何实盘账户中运行。
