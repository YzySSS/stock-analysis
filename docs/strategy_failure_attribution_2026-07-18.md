# 冻结策略失败归因（2026-07-18）

## 1. 目标与边界

本切片承接 `historical_diagnostic_fail`，回答两个更窄的问题：当前版本为什么失败，以及只改变持有期/换仓方式是否足以形成一个可信的新版本。

分析对象保持为两条不可变历史 run：

- 低波反转：`backtest_lowvol_reversal_20260718_002337_693871`；
- 三因子：`backtest_v13_three_factor_20260718_010249_400303`。

本切片没有修改旧策略、Selector、Backtest Service/Repository 或股票池政策，也没有创建新回测 run、schema 或线上任务。两份 2026-07-20 起的真正前瞻协议源码指纹复核仍为 `MATCH`。

所有结果继续是已观察历史数据上的失败归因，不是新的样本外验证。不会因为某个月、某个 offset 或某个排名表现较好而回调权重、阈值或再平衡起点。

## 2. 可重复工具

新增只读垂直切片：

- `app/backtest/failure_attribution_repository.py`：读取 run、每日摘要、交易明细、后续行情和指数历史；
- `app/backtest/failure_attribution.py`：统一计算毛/净收益、因子秩相关、持仓留存、非重叠再平衡 cohort 和市场阶段；
- `scripts/run_strategy_failure_attribution.py`：命令行输出确定性 JSON 报告；
- `tests/test_backtest_failure_attribution.py`：覆盖成本、缺失值、Spearman、全部 offset 和换仓留存。

执行入口：

```bash
PYTHONPATH=. .venv/bin/python scripts/run_strategy_failure_attribution.py \
  --run-id backtest_lowvol_reversal_20260718_002337_693871 \
  --run-id backtest_v13_three_factor_20260718_010249_400303
```

前瞻收益缺失保持为缺失并报告数量，不补零。3/5/10 日执行假设按全部 offset 分别计算；只有全部 offset 同时为正，才把“仅修改执行周期”视为稳健候选。

## 3. 成本与持有期归因

真实成本口径为佣金每边 3 bps、卖出印花税 5 bps、滑点每边 5 bps，单次往返拖累 `0.209832%`。

| 指标 | 低波反转 v2.1 | 三因子 v0.1.0 |
|---|---:|---:|
| 1 日毛收益复利 | -6.7309% | +0.4824% |
| 1 日净收益复利 | -43.4252% | -39.0498% |
| 1 日单笔毛收益均值 | -0.025687% | +0.014337% |
| 1 日单笔净收益均值 | -0.235466% | -0.195526% |
| 3 日单笔毛 / 净均值 | +0.017491% / -0.192378% | +0.169904% / -0.040284% |
| 5 日单笔毛 / 净均值 | -0.104855% / -0.314467% | +0.280121% / +0.069701% |
| 10 日单笔毛 / 净均值 | -0.391406% / -0.600416% | +0.355222% / +0.144644% |

低波在扣费前已经没有正边际，成本只是放大失败。三因子在 3～10 日出现很薄的单笔毛边际，但中位数和胜率没有同步改善，不能用均值直接宣称策略有效。

非重叠 3 日再平衡结果更能说明稳定性：

- 低波三个净收益 offset 分别为 `-12.9985% / -13.2227% / -19.5347%`；
- 三因子三个净收益 offset 分别为 `-5.7802% / -22.0879% / +12.0806%`。

三因子的正结果集中在单一 offset，5 日和 10 日也同时存在明显正负分化。挑最好 offset 会形成典型的历史择时过拟合，因此 3/5/10 日的“全部 offset 为正”检查均失败，只改持有期的 V13 新版本不成立。

## 4. 因子排序与换仓归因

低波总分和未来毛收益的 Spearman IC 为：

- 1 日 `-0.084299`；
- 3 日 `-0.133208`；
- 5 日 `-0.144282`。

其中 reversal 因子在 3/5 日分别为 `-0.123226 / -0.146166`。分数越高反而越差，且第 3 名在三个期限上优于第 1 名，属于因子方向/组合定义失败，不适合继续围绕原权重小修小补。

三因子总分 IC 为 `-0.071728 / -0.014566 / -0.025115`，基本没有排序能力。714 个入选中只有 504 个不同代码；相邻信号日平均只保留 `7.6072%` 的持仓，估算 714 次完整往返只能降低到 659 次。即使允许保留重合股票，净收益反事实近似仍为 `-36.6568%`。

低波相邻日留存为 `38.3126%`，往返可从 714 降至 437 次，但保留持仓成本近似仍为 `-31.3163%`。因此两条策略都不能单靠“别每天卖掉重买”修复。

## 5. 门槛与候选分布

使用同一 PIT 候选加载器重算 2025-07 至 2026-06 每月一个代表日，共 12 个日期：

| 代表日中位数 | 低波反转 | 三因子 |
|---|---:|---:|
| 可评分候选 | 4,812 | 3,942.5 |
| 通过原阈值候选 | 1,869 | 2,649.5 |
| 通过比例 | 38.91% | 66.55% |
| 第 3 与第 4 名分差 | 0.07 | 0.09 |
| 前 3 名分数跨度 | 0.885 | 0.19 |

原来的 60/65 分阈值没有形成入场门槛；策略每天都从大量几乎同分的候选中强制选满 3 只。低波还叠加全局低价加分并在部分日期出现多只 100 分，进一步压缩顶部辨识度。这里没有根据历史结果临时抬高阈值，因为那只会把同一段失败样本变成调参集。

## 6. 结论与下一版本约束

归因分类：

- 低波反转：`factor_direction_failure`；
- 三因子：`weak_signal_destroyed_by_turnover_costs`，但执行周期替换不具备跨 offset 稳健性。

因此当前两版均保持 `reject_as_effective_strategy / research_only / validation_pending / unvalidated`。本轮不创建或启用 V14，也不修改旧配置。

下一策略版本必须满足以下边界：

1. 使用与当前低波/反转/换手组合相互独立的新信号家族，不能只换权重；
2. 在设计前冻结训练区间、诊断区间、持有周期、成本和跨 offset 稳健性门槛；
3. 允许无信号时持币，不再固定每天选满 3 只；
4. 策略分数必须有清晰的横截面区分度，且关闭与 alpha 无关的绝对股价加分；
5. 新版本使用独立策略 ID、实现文件和前瞻协议，不能覆盖两份现有 V2 冻结实验。

候选方向优先考虑公告日 PIT 质量因子、趋势确认和流动性约束，但必须先写研究协议，再看结果；不能从这段已观察历史中挑出最赚钱的组合后冒充样本外发现。
