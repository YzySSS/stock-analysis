## P3 - 扩大基本面同步批次

原因：
- 当前只有 **67 / 5200** 覆盖
- 是当前影响“页面可信度”的最大瓶颈

### 使用入口
- `app.data_ingestion.fundamental_sync`

### 当前脚本特点
已具备：
- 自动补字段列
- 候选筛选
- 按缺失优先
- 多报告期回退
- 频控等待
- 任务日志记录

### 建议执行策略
先别一次性冲太猛，采用：
- 小批量验证
- 中批量稳定化
- 再扩大

建议顺序：
1. `limit=100`
2. `limit=300`
3. 再评估频控与成功率

### 推荐跑法
```bash

```

如果后面要增强，优先考虑扩成支持：
- `limit` 参数
- `offset` 或 code 列表
- 更细粒度失败重试

当前脚本能用，但后续如果要大规模补全，建议把批量控制做得再显式一些。
