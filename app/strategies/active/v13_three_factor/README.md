# V13 三因子策略

这是新模块化架构下的首个可插拔策略模板。

## 当前定位

当前版本先完成三件事：

1. 定义策略独立目录
2. 定义统一输入输出接口
3. 固定策略配置位置

还没有完成的内容：

- 真实因子计算迁移
- 与腾讯云 MySQL 的标准化读取接入
- 与回测模块共用同一策略入口
- 市场状态自适应扩展

## 核心因子

- turnover
- lowvol
- reversal

## 配置文件

- `config.yaml`：策略元信息与参数
- `strategy.py`：策略实现模板
