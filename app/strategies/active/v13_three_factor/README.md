# 三因子策略

这是新模块化架构下的首个可插拔策略模板。

## 当前定位

当前版本先完成三件事：

1. 定义策略独立目录
2. 定义统一输入输出接口
3. 固定策略配置位置

当前已完成：

- 接入选股中心统一 `StockSelector` 执行协议
- 使用 `factor_input_daily` 的换手率/量比，以及最新 20 日行情窗口计算三因子
- 增加价格、20 日成交额、历史长度、ST 与因子输入可用性过滤

还没有完成的内容：

- 与回测模块共用同一策略入口
- 市场状态自适应扩展
- 更严格的历史样本外验证

## 核心因子

- turnover
- lowvol
- reversal

## 配置文件

- `config.yaml`：策略元信息与参数
- `strategy.py`：策略实现模板

## 后续迁移方向

- 分数阈值筛选逻辑
- 最大持仓数限制
- 与数据层对接的特征读取逻辑
